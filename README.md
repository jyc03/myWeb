# myWeb

使用 AI 建立的第一個 RWD 響應式網頁，適合在 GitHub Pages 公開展示。

## 網頁內容
- 首頁介紹
- 關於網站
- 網站特色（RWD、視覺設計、GitHub Pages）
- 學習心得

## GitHub Pages 發布方式
1. 登入 GitHub，新增公開儲存庫，名稱設為 `myWeb`。
2. 點選 **Add file → Upload files**，將 `index.html` 與 `README.md` 上傳到儲存庫根目錄，點選 **Commit changes**。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/(root)`，按 **Save**。
5. 等部署完成後，網址通常為 `https://你的GitHub帳號.github.io/myWeb/`。
