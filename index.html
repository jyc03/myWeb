關於這個網站

從零開始認識網頁設計與 GitHub

學習心得

這次作業讓我了解 GitHub 不只是存放程式碼的平台，也能用來展示自己製作的網頁。透過 AI 協助，我學會了 HTML 是網頁的基本架構，CSS 可以調整顏色、字型與排版，而 RWD 能讓網頁在不同裝置上維持良好的閱讀體驗。完成網頁後，我也能練習將檔案上傳至 GitHub，進一步學習使用 GitHub Pages 發布網站。這次的學習經驗讓我發現，即使沒有太多程式基礎，也可以一步一步製作出屬於自己的網站。
